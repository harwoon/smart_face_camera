# AR 아이템 에셋

여기에 **배경이 투명한 PNG**를 넣으세요.

## 필요한 파일

| 파일명 | 용도 |
|---|---|
| `hat.png` | 모자 |
| `glasses.png` | 선글라스 |
| `mustache.png` | 수염 |
| (자유) | 추가 아이템 |

## 조건

- 반드시 **알파 채널(4채널) PNG**여야 합니다.
  JPG나 배경이 흰색인 PNG를 쓰면 검은/흰 사각형이 붙습니다.
- 확인 방법:
  ```python
  import cv2
  img = cv2.imread('assets/hat.png', cv2.IMREAD_UNCHANGED)
  print(img.shape)   # (h, w, 4) 여야 정상. (h, w, 3)이면 알파 없음
  ```
- 아이템의 여백을 최대한 잘라내고 저장하면 좌표 맞추기가 훨씬 쉽습니다.
- 구하는 곳: "transparent png" 키워드로 검색하거나
  직접 그려도 됩니다. 저작권 표기가 필요한 소스는 발표 자료에 출처를 남기세요.

## 좌표 감 (얼굴 박스 x, y, w, h 기준)

| 아이템 | 세로 위치 | 폭 |
|---|---|---|
| 모자 | `y - h*0.5` 부근 | `w * 1.2` |
| 선글라스 | `y + h*0.25` 부근 | `w * 1.0` |
| 수염 | `y + h*0.6` 부근 | `w * 0.5` |
